Blip for Windows: iMessage on Windows through a Mac you own.

**Download** `Blip for Windows_<version>_x64-setup.exe` below and run it.
It installs for your user only. The first run walks you through connecting
to your Mac. See the [Windows README](https://github.com/chrisandtre/blip-windows/blob/windows-client/windows/README.md)
for what you need.

**New in 0.2.0: reactions (beta).** Turn on Reactions (beta) in the tray
menu, then right-click or double-click a message to heart, like, laugh and
so on. Picking a reaction you already sent removes it. The Mac needs the
updated bridge: re-run setup with `-UpdateMac` after installing. Messages
comes to the front on the Mac for a few seconds while it works.

The installer is not code-signed yet, so Windows SmartScreen may say the
publisher is unknown: choose More info > Run anyway.

Built on [Blip](https://github.com/nixfred/blip) by Fred Nix: same Mac bridge,
same core, Windows app on top.
